# Realistic Shader Renderer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the fixed-function OpenGL renderer with an embedded-GLSL HDR renderer (PBR lighting, sun shadow maps, bloom, SSAO, procedural bump materials, volumetric god rays, dust, FPV movement feel) without changing geometry or breaking existing controls.

**Architecture:** Keep the existing display lists; shaders read legacy attributes through a GL 3.3 compatibility context. A new `realistic_renderer.py` owns shaders, FBOs, matrices and the pass pipeline; `classroom.py` builds geometry, tags materials via secondary colour, and drives `Renderer.render(FrameState)`.

**Tech Stack:** Python 3.10+, PyOpenGL 3.1.10, glfw 2.10.2, Pillow ≥ 10, GLSL `330 compatibility`, `unittest`.

**Spec:** [docs/superpowers/specs/2026-10-15-realistic-shader-renderer-design.md](../specs/2026-10-15-realistic-shader-renderer-design.md)

## Global Constraints

- No new dependencies (no numpy). Pure-Python 4×4 matrices, column-major lists passed to `glUniformMatrix4fv`.
- No external asset files. GLSL lives in Python string constants in `realistic_renderer.py`.
- All textures generated by Pillow in `surface_materials.py`; `make_surface_images()` signature unchanged.
- Context: `CONTEXT_VERSION_MAJOR=3`, `MINOR=3`, no core-profile hint. Shaders: `#version 330 compatibility`.
- No fixed-function fallback. After Task 2, no `glLight*`, `glMaterial*`, `GL_LIGHTING`, `GL_COLOR_MATERIAL` remain anywhere.
- Geometry, dimensions and layout from `GEMINI.md` / `room_config.json` unchanged.
- Every task ends with: `python -m py_compile classroom.py surface_materials.py realistic_renderer.py` → exit 0; `python -m unittest discover tests` → OK; `python classroom.py --hidden --verify previews` → exit 0, `opengl_errors == 0`.
- The workspace is not a git repository: there are no commit steps. Instead, each task updates its checkbox in the task tracker.
- Preserve existing comments and docstrings.

## Review Focus

1. **Window resize / minimise to 0×0** — all FBOs must reallocate on resize and skip rendering at 0 size without GL errors. (Test in Task 1.)
2. **Slider extremes** (sun 0, interior 0, exposure ±2, bloom 0, softness 0/1) — no NaN/black-screen/white-out; image stays finite. (Test in Task 3.)
3. **Quality toggle mid-session and during the tour** — reallocation must not leak textures or raise errors. (Test in Task 6.)
4. **Interior lights off at Sunset with sun 0** — the scene must not go pure black (ambient floor > 0). (Test in Task 2.)
5. **Shader compile failure on a different driver** — must raise with the full info log instead of rendering garbage. (Test in Task 1.)
