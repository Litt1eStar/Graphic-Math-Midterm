# โมเดลห้อง S13-30612 — เวอร์ชัน 14

โปรแกรม Python + PyOpenGL จำลองห้องชั้น 6 จากภาพถ่าย ภาพวัดระยะ แปลน และคำแก้ไขของผู้ใช้ ห้องและวัตถุสามมิติวาดด้วย OpenGL จริง; GLFW สร้างหน้าต่างและรับอินพุต ส่วน Pillow สร้างภาพพื้นผิวและข้อความ

## เปิดใช้งาน

1. แตก ZIP ทั้งโฟลเดอร์ แล้วเปิด `run.bat` หรือ `S13-30612.exe`
2. เก็บ `room_config.json` ไว้ข้าง EXE เสมอ
3. ถ้าเปิดโปรแกรมรุ่นก่อนค้างอยู่ ให้ปิดแล้วเปิดใหม่เพื่อโหลดรุ่นนี้

EXE รวม Python และไลบรารีแล้ว ใช้กับ Windows 64 บิตและไดรเวอร์การ์ดจอที่รองรับ OpenGL compatibility หากต้องการแก้หรือรันซอร์ส ให้เก็บ **`classroom.py` และ `surface_materials.py` ไว้ด้วยกัน** พร้อม `room_config.json` ใช้ Python 3.10 ขึ้นไป รัน `setup_python.bat` ครั้งเดียว แล้วสั่ง:

```bat
.venv\Scripts\python.exe classroom.py
```

บนระบบอื่นติดตั้งด้วย `python -m pip install -r requirements.txt` แล้วรัน `python classroom.py`

## ผังและรายละเอียดที่ใช้ล่าสุด

รายการนี้สรุปคำแก้ไขที่ยอมรับแล้ว และใช้แทนคำอธิบายรุ่นเก่าที่อาจต่างกัน:

- **ทางเข้า:** โถงต่อด้านหลังฝั่งขวา โดยนับขวาเมื่อยืนในห้องแล้วหันไปทางจอฉาย โถงกว้าง 2.90 ม. ลึก 4.01 ม. ประตูกว้าง 2.30 ม. ขอบขวาชิดผนัง แถบผนังซ้ายประตู 0.60 ม. เสาซ้ายปากโถงยื่น 0.25 ม. ทั้งหมดเป็นสัดส่วนประมาณจากภาพ
- **โต๊ะนักเรียน:** สองโต๊ะติดกัน นั่งคู่ละสี่คน เป็นสามชุดตามแนวลึก ซ้าย กลาง ขวา ชุดริมชิดผนังหรือหน้าเสาเพื่อไม่ให้ชนเสา ปัจจุบันใช้หกแถว รวม 36 โต๊ะและ 72 เก้าอี้ จำนวนแถวยังเป็นค่าตั้งต้น
- **เก้าอี้นักเรียน:** เบาะและพนักพิงดำขอบมน โครงท่อโครเมียม ขาหน้าเกือบตั้งตรง ขาหลังเอียงออก ท่อโค้งเชื่อมพื้นเป็นโครงสี่เหลี่ยมคางหมู พร้อมป้ายเล็กหลังพนักพิง
- **โต๊ะอาจารย์:** โต๊ะยาว 3.20 ม. หน้าห้องฝั่งซ้าย ขอบติดโต๊ะนักเรียนคู่หน้าสุดและสูงเสมอกัน มี iMac คีย์บอร์ดและเมาส์ จอหันเข้าผนัง ผู้สอนนั่งฝั่งผนังหันออกมาทางห้อง ใช้เก้าอี้พนักพิงสูงเบาะมนพร้อมที่วางแขนและฐานล้อ ไม่มีเคสแยก
- **จอและแอร์:** จอฉายใหญ่หน้าห้อง ทีวีตั้งพื้นด้านขวาหนึ่งตัว ทีวีติดคานเหนือโต๊ะกลางห้องสองตัวพร้อมขายึดต่อถึงคาน แอร์ใต้ฝ้าสี่ตัว ฝั่งละสอง พร้อมช่องดูดลมด้านล่าง
- **งานระบบ:** ประตูกระจกกรอบดำมีช่องแสง พัดลม บานพับ โช้คและมือจับ; หลอดกลมคู่พร้อมรางโคม; ท่อโค้งหลบเสาและคลิปยึด; สวิตช์ เต้ารับ คัตเอาต์และรีโมต
- **คัตเอาต์ที่วงล่าสุด:** ชุดบนผนัง X=0 อยู่ใกล้เสากลางที่ Y=7.00 ม. ยกขึ้น 0.40 ม. จากตำแหน่งรุ่น 12 มีรีโมตหนึ่งอัน และท่อแนวดิ่งตามตำแหน่งใหม่ ตามคำแก้ไขรุ่น 13
- **ผนังและโถง:** ช่องผนังด้านข้างช่วงหน้าห้องที่วงเป็นหน้าต่าง โถงมีช่องเปิดซ่อมฝ้าสองช่อง แนวรอยต่อผนัง และกล้องวงจรปิดฐานกลมติดคานพร้อมหัวปรับมุมและช่องเลนส์สองช่อง
- **สิ่งที่ลบตามคำขอ:** เสากลางผนังหลังห้อง โต๊ะเดี่ยวในโถง แท่นไม้หน้าห้อง ลำโพง และทีวีเล็กเหนือผนังหน้าห้อง

เวอร์ชัน 14 ปรับผิวโต๊ะเป็นไม้สีอ่อนลายละเอียด ขอบหนา 28 มม. แยกพื้นผิวผนังไม้ ปรับแสงเพดานและเงาสัมผัสใต้เฟอร์นิเจอร์ กระจกมีสีเป็นกลางขึ้น ฉากกลางวันหลังหน้าต่างและพื้นที่ด้านนอกพร้อมบอร์ดประกาศเป็น **ฉากประกอบแบบทั่วไปที่สร้างขึ้น** เพื่อให้เห็นความโปร่งใส ไม่ใช่การสำรวจหรือจำลองอาคารภายนอกอย่างแม่นยำ

## ขนาดและความแน่นอน

หน่วยคือเมตร แกน X/Y อยู่บนพื้น Z เป็นความสูง หน้าห้องอยู่ Y=0 โถงอยู่ X=0–2.90 และ Y=12.10–16.11

| รายการ | ค่าในโมเดล | สถานะ |
|---|---:|---|
| ความสูง | 3.46 ม. | ผู้ใช้ยืนยัน |
| ด้านหลักไม่รวมทางเข้า (X) | 11.79 ม. | เห็นในภาพวัด; ผู้ใช้ยืนยันด้านประมาณ 11 เมตร |
| อีกด้านของห้อง (Y) | 12.10 ม. | ภาพมี 12.10/12.15; การจับคู่ด้านยังประมาณ |
| โถง กว้าง × ลึก | 2.90 × 4.01 ม. | ประมาณจากรูปและคำแก้ไข |
| ประตู สูง × กว้าง | 2.75 × 2.30 ม. | การจับคู่ความสูงและความกว้างยังประมาณ |
| เสาทั่วไป | 0.60 × 0.60 ม. | การจับคู่ค่า 0.60 กับเสายังประมาณ |
| เสาซ้ายปากโถง | ยื่น 0.25 ม. | ประมาณตามคำขอให้บางลง |
| ผนัง | หนา 0.18 ม. | สมมติสำหรับโมเดล |

แปลนระบุพื้นที่ 155.25 ตร.ม. ขณะที่พื้นที่พื้นรวมตามค่าปัจจุบันคือ 154.288 ตร.ม. ไม่ได้บังคับขนาดให้ตรงพื้นที่แปลน จำนวน 80 ที่นั่งในตารางแปลนไม่ใช่การตรวจนับเก้าอี้ปัจจุบัน ขนาดช่องเปิด เฟอร์นิเจอร์ งานระบบ และจำนวนหกแถวเป็นการประมาณจากภาพ จึงยังไม่ใช่แบบสำรวจที่ยืนยันครบทุกระยะ

แก้ขนาดใน `room_config.json` แล้วเปิดใหม่ ใช้ `room.width`, `depth`, `height` สำหรับห้อง และ `furniture.rows`, `table_width`, `row_spacing` สำหรับโต๊ะ โดยเก็บคีย์อื่นทั้งหมดไว้ โปรแกรมตรวจขนาดและการจัดแถวเบื้องต้น

## โค้ดและไฟล์ส่งงาน

| ไฟล์/ส่วน | หน้าที่ |
|---|---|
| `classroom.py` | สร้างรูปทรง กล้อง แสง วาด OpenGL และรับอินพุต |
| `surface_materials.py` | สร้างพื้นผิวไม้ หินขัด และฉากกลางวันแบบทั่วไป ต้องอยู่ข้างซอร์สหลัก |
| `room_config.json` | ขนาด ผังโต๊ะ และบันทึกที่มา |
| `data/` | ภาพ/แปลนอ้างอิงและ `sources.json` |
| `previews/` | ภาพจาก OpenGL จริงและรายงานตรวจโปรแกรม |
| `PRESENTATION_TH.md` | ลำดับสาธิตภายในห้านาที |
| `requirements.txt`, `setup_python.bat`, `run.bat` | ติดตั้งและเปิดโปรแกรม |

`Classroom.build()` สร้างรูปทรงเป็นเมตร; `tube()` และ `cushion()` สร้าง mesh พร้อม normals; `compile()` ใช้ display lists; `Camera.vectors()` คำนวณกล้อง; `App.render()` ตั้ง perspective และ `gluLookAt()` ประตูใช้ translation ไปบานพับแล้ว rotation กระจกใช้ alpha blending ส่วน HUD ใช้ orthographic projection เงาสัมผัสเป็นการไล่ความเข้มแบบประมาณ ไม่ใช่การคำนวณเงาทางกายภาพ

ใช้ OpenGL fixed-function / compatibility API เพื่ออธิบาย transformation, projection, lighting และการสร้างเรขาคณิตได้ตรงกับโค้ด

เอกสาร: [PyOpenGL](https://pyopengl.sourceforge.net/documentation/), [GLFW Python](https://github.com/FlorianRhiem/pyGLFW), [GLFW](https://www.glfw.org/docs/latest/)
